# CopyKeepass
## A python program to copy your keepass database

### Is your keepass database broken? Do you want to rename it? Do you want to copy it automatically, without typing hundreds of passwords, comments and entries? 
### CopyKeepass is here!


## Download and run
- open this project in a python IDE ( VS Code and PyCharm are recommanded)
- click start/green triangle

## Input
- the program takes as input the path to the __file you want to copy__ (old file) *Warning: provide the exact path*
- the program takes as input the path to the __file you want to create__ (new file)

- the program takes as input the __password__ to the __file you want to copy (old file)__
- the program takes as input the __password__ to the __file you want to create (new file)__  *Warning: create a strong password*
